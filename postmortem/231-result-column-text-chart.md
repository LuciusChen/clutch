# Result column text chart

`B` charts the numeric column at point as horizontal bars, one per row of the current page, in a `clutch-chart-mode` buffer of its own. The chart reads `clutch--result-display-rows` and so follows the client filter and the local sort exactly as the grid shows them; it covers only the current page, which its heading states with the row range, and never fetches more rows. Drawing into the result buffer itself was rejected: the grid owns row start positions, pixel padding, the header line and hscroll, and every one of them would have to learn to skip chart text.

Drawing lives in `clutch-viz.el`, pure functions over Lisp data with no Clutch dependency, which the architecture check enforces by giving the module an empty allowlist. The bar algorithm follows glyph-kit's (eighths of a cell, a positive value never drawn empty, a value past the top clamped), but glyph-kit itself is not used: its CLI needs Node, caps a figure at 16 rows, 24-cell labels and 80 columns, refuses numbers without a stated source, and measures width with a fixed table in which box and block characters are always one cell.

Emacs's own width rules are what matter. In a CJK language environment with `cjk-ambiguous-chars-are-wide`, `█`, `▏` and `…` become two columns while `░` stays one (checked on Emacs 32), so `clutch-viz-charset` falls back to `#` whenever a block character is not one column. Labels and bars are padded with real spaces, so copied text stays aligned, carrying a `(space :align-to COL)` display property, so a graphical frame aligns even when a CJK or fallback glyph is not an exact multiple of the default width.

Values are numbers when `clutch-result--parse-number` reads them, which covers decimal strings from JDBC `BigDecimal` and the native adapters; overflowing values such as `1e999` and anything that is not a number draw no bar and are counted in the heading. The shown text is the formatted cell value, so decimals keep their digits even though the bar uses a float. A chart is redrawn only on `g`, from the result's current page at the window's width; a result whose columns no longer match is refused rather than charted against the wrong column. A refresh hook on the result's render path was deferred until there is a demonstrated need, to keep the grid's hot path unchanged.
